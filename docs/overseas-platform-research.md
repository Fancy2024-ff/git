### 🔥 近期热门案例（含爆火原因深度分析）

##### 案例1：Hamster Kombat（仓鼠快打）— 73天破亿用户

- **类型：**Tap-to-Earn 点击类游戏
- **上线时间：**2024年3月26日
- **数据：**上线73天突破1亿用户，累计3亿+下载，YouTube 频道 3500万订阅

**🔍 为什么爆火？踩中了哪些热点？**

1. **空投预期驱动（核心引擎）：**团队明确承诺会发代币空投，玩家相信"现在点击 = 以后能换真钱"，形成了强烈的 FOMO（错过恐惧）心理。这不是游戏，是"免费彩票"心态。
2. **零门槛 + 极简操作：**不需要下载 App、不需要钱包、不需要注册，打开 Telegram 点屏幕就行。传统 Web3 游戏需要买 NFT/注册钱包，Hamster 直接消除了所有障碍。
3. **"Profit Per Hour"机制设计：**团队设计了"每小时收益"指标，明确告诉玩家空投分配看的是 PPH 而非简单点击次数，驱动玩家研究升级策略、每天回来操作，提升了留存。
4. **社交裂变（邀请奖励）：**邀请好友获得额外奖励，一个人拉一个群，指数级传播。在中东/俄语区/东南亚"赚钱效应"传播极快。
5. **Meme 文化加持：**"仓鼠" IP 天然有 Meme 属性，配合加密货币文化中的动物 Meme（狗/青蛙/仓鼠），自带传播力。
6. **时间窗口：**恰好在 TON 生态爆发期推出，Telegram 官方也在推 Mini App 生态，获得了平台级流量红利。

**⚠️ 后续：**代币上线后价格暴跌，大量用户失望离开。验证了"空投预期"是把双刃剑——能拉新但难留存。

##### 案例2：Notcoin（$NOT）— 开创 Tap-to-Earn 品类的鼻祖

- **类型：**Tap-to-Earn 挖矿游戏（后转型为社区平台）
- **上线时间：**2024年1月1日（代币上线 Binance：2024年5月16日）
- **数据：**4000万+用户，代币上线后市值超10亿美元，上线 Binance/OKX 等主流交易所

**🔍 为什么爆火？踩中了哪些热点？**

1. **第一个吃螃蟹（先发优势）：**Notcoin 是 TON 生态第一个成功的 Mini App 游戏，没有竞品，市场一片蓝海。后面所有 Tap-to-Earn 都是模仿它。
2. **零注册摩擦：**创始人 Sasha 的核心策略——"删除所有注册环节"。不需要钱包、不需要登录、不需要投资，Telegram 用户点开就能玩。官方总结为"remove all onboarding requirements"。
3. **TON 生态 +** **Telegram** **官方背书：**Telegram 创始人 Pavel Durov 公开支持 TON，Notcoin 选择 TON 链是"蓝海策略"，竞争少且有平台加持。
4. **真的兑现了（空投真给了）：**与后来很多项目不同，Notcoin 真的把代币空投给了玩家，而且代币上了 Binance 等大所，形成了"点手机真能赚钱"的口碑效应，带动了整个品类。
5. **社交裂变 + 社区文化：**邀请好友奖励 + Telegram 群组天然社交传播。创始人说"这不只是游戏，是社区和文化"。
6. **简单到极致的产品设计：**一个按钮、一个数字。用户不需要"学会"任何东西，5秒内理解玩法。

**💡 启示：**Notcoin 证明了"极简 + 免费 + 社交裂变 + 真实奖励"的公式在 Telegram 生态能产生爆发式增长。但创始人也警告"纯抄模式的点点游戏通常会失败"。

### 📋 详细提交流程与所需材料

第1步：在 Telegram 中搜索 @BotFather，发送 /newbot 创建一个 Bot      → 需要：Bot 名称 + 用户名（以bot结尾） 第2步：发送 /newapp 注册你的 Mini App，关联到刚创建的 Bot      → 需要：应用标题、简短描述、应用图标（640×640 PNG） 第3步：将你的网页应用部署到 HTTPS 服务器      → 可用免费平台：Vercel / Netlify / Cloudflare Pages / GitHub Pages 第4步：将部署后的 URL 配置到 BotFather      → 发送 /myapps → 选择 App → Edit Web App URL → 粘贴 URL 第5步：完成！用户通过 Bot 链接即可打开你的 Mini App

- 如涉及加密货币/金融，需自行确认目标地区法规

##### 案例1：Discord 官方内置 Activities（Poker Night / Sketch Heads / Watch Together）

- **类型：**多人实时互动应用（游戏/工具）
- **上线时间：**2022年底开始测试，2024年全面开放，2026年持续扩展

**🔍 为什么这些 Activities 火？**

1. **解决了"一起在线干什么"的问题：**Discord 用户本来就在语音频道挂着聊天，Activities 给了一个"边聊边玩"的理由，填充了社交空白时间。不是"专门来玩游戏"，而是"顺便玩一下"。
2. **零摩擦启动：**不需要所有人都下载一个游戏，在语音频道里点一下就所有人一起进入，完美匹配 Discord "随时随地开搞"的使用场景。
3. **社交压力驱动：**"大家都在玩，你不来吗？" 频道里有人发起 Activity，其他人自然会加入，形成群体参与效应。
4. **平台官方流量扶持：**Discord 把 Activities 放在语音频道的显眼入口（App Launcher），不需要额外推广。

### 📋 详细提交流程与所需材料

### 🔥 平台热门游戏（含分析）

##### YouTube Playables 上线游戏特点

- **类型：**休闲/益智/街机类（消除、跑酷、解谜、打砖块）
- **特点：**极度轻量、加载快、单局时间短

**🔍 什么样的游戏适合 YouTube Playables？**

1. **"随手玩一局"场景：**YouTube 用户是来看视频的，不是来打游戏的。Playables 必须在视频间隙就能玩完一局（30秒-3分钟），不能有复杂的进度系统。
2. **重复性 + 上瘾性：**成功的 Playable 都是"再来一局"型的，简单规则但有变化，让用户一直点 Retry。类似 Flappy Bird 的设计哲学。
3. **技术极限优化：**初始包要求 < 15MB（建议 5MB），不能有外部请求。这意味着画面不能太精细，但玩法必须吸引人。成功的游戏都是"玩法优先"而非"画面优先"。
4. **广告变现需按平台规则接入：**如启用广告，应使用 YouTube 允许的广告能力；不要在报告中承诺 CPM 或固定分成，具体模式需通过 Google / 合作伙伴确认。

**💡 对我们的启示：**如果有现成的 HTML5 小游戏（消除/跑酷/解谜），可以通过 Playgama 等合作伙伴快速接入。但开发限制多，不适合作为首选试水平台。

### 📋 详细提交流程与所需材料

第1步：使用兼容引擎开发 HTML5 游戏      → 推荐：Cocos Creator / Phaser / PixiJS / Unity WebGL 第2步：集成 YouTube Playables SDK      → 处理：firstFrameReady / gameReady / 暂停 / 静音 / 保存进度 第3步：适配多设备多比例      → 必须支持：1:1、16:9、9:16 三种比例      → 必须支持：触控 + 键鼠 第4步：打包为 ZIP 文件      → 初始包 < 15 MB（建议 < 5 MB）      → 总包 < 250 MB（建议 < 15 MB）      → 单文件 < 30 MB 第5步：通过合作伙伴（如 Playgama）或直接联系 Google 提交 第6步：进入 Certification 认证流程      → 审核维度：技术集成 / 设计规范 / 稳定性 / 内容安全 第7步：认证通过 → 上线 YouTube Playables
