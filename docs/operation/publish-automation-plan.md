# 上架自动化路线图

> 更新时间: 2026-06-12
> 状态: MVP 阶段，部分自动化

## 微信小程序

| 步骤 | 自动化程度 | 当前状态 | 工具/方式 |
|------|-----------|----------|-----------|
| 代码生成 | 已自动化 | ✅ 系统自动 | uni-app + CodegenAgent |
| 代码构建 | 已自动化 | ✅ 系统自动 | npm run build:mp-weixin |
| 代码上传 | 可自动化 | ❌ 未实现 | miniprogram-ci (需私钥) |
| 填写应用信息 | 可半自动 | ❌ 未实现 | API + 人工确认 |
| 提交审核 | 可自动化 | ❌ 未实现 | miniprogram-ci --upload |
| 审核结果获取 | 可自动化 | ❌ 未实现 | 审核回调 webhook |
| 发布上线 | 需人工 | ❌ 人工 | 管理员扫码确认 |

**下一步实现**: 接入 miniprogram-ci，实现代码上传 + 提交审核自动化。
**阻塞项**: 需要小程序管理员提供上传私钥文件。
